# ハンズオン 全体の流れ

> 参加者に最初に見せる「地図」。EDINETの有報データを取得し、Claude Codeで財務ダッシュボードを作り、スキル化して別企業へ横展開するまでを体感する。
> 図版：[`全体の流れ.svg`](全体の流れ.svg)（スライド貼り付け用）。

---

## 1. ゴールの共有

- **やること**：EDINETからデータを取得し、**財務ダッシュボードを作成**する。
- **なぜこの課題か**：**人間が扱うには複雑すぎるデータ（XBRL）を、AIで解決する**という、Claude Codeの得意領域を最も分かりやすく体感できるから。
- 到達イメージ：複雑な有報が、数分でインタラクティブなダッシュボードに変わる。

## 2. 課題の説明と準備

- **EDINETとは**：金融庁の電子開示システム。上場企業の有価証券報告書などが公開されている。
- **データの取得、もしくは配布**
  - **Webからの取得方法を解説**（＝手段1。キー不要・ブラウザのみ）。→ `手段1_EDINET手動DL手順.md`
  - **APIは補足的に扱う**（登録が要るので当日は深入りしない）。
  - 当日の安全網として**配布データ**も用意（＝手段2）。→ `data/`
- **XBRLとは**（**実際のコードを見せつつ**）
  - タクソノミ／インスタンス／ファクト／コンテキスト等、**周辺用語も解説**。→ `教材/XBRL入門.md`＋`教材/xbrl-structure.svg`
- **ゴールのサンプルを見せる**
  - **作成済みのもの**（ARE／松田産業のダッシュボード）。→ `artifacts/…財務ダッシュボード.html`
  - **バフェットコード**を「こういう財務可視化のイメージ」として提示（＝今日作るのはその簡易版）。

## 3. 実際に行う（1社目）

- **フォルダの指定**：作業フォルダ（有報データの場所）をClaude Codeに教える。
- **プロンプトの書き方**：「このXBRLを解析して主要財務をダッシュボードにして」等、指示の出し方。
- **カスタマイズ**：出てきたダッシュボードを対話で直しながら仕上げる（試行錯誤の体感）。

## 4. スキル化 → 2社目

- **なぜスキル化か**：**毎回同じプロンプトを打つのは大変**だし、**再現性も出しにくい**。手順を固めて再利用資産にする。
- **Claude周辺の用語を解説**：スキル（`SKILL.md`）、`CLAUDE.md`、エージェント、プロンプト、権限確認など。→（用語集は別途作成予定）
- **実際にスキル化**：1社目の手順を `SKILL.md` にまとめる。→ 完成形サンプル `skills/edinet-xbrl-dashboard/`
- **別の企業をスキルで作ってみる**
  - 教材データも用意するが、**自分で好きな企業を選んでもらう** ← ここがハンズオンの楽しさ。
  - 「1社目は試行錯誤、2社目は数分」を自分の手で体感。

## 5. 今後について

- **APIを使えば、いろんな企業を取得できる**（横展開の幅が広がる）。
- おおよそ**バフェットコードの簡易版のようなもの**は自分で作れるようになる、という到達点の提示。
