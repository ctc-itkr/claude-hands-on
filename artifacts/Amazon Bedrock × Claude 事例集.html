Amazon Bedrock ✕ Claude · 事例集

Claude を自社 AWS の中で使う導入事例

Amazon Bedrock で Claude を活用した実事例のまとめ。いずれも自社の AWS 環境（統制下）で Claude を組み込むパターンです。冒頭の NEC は、Cowork（Claude Desktop）の推論バックエンドを Bedrock にした全社導入の代表例です。

01

全社 AI 基盤（Cowork on Bedrock）

NEC

2週間で最大12万人規模のセキュアな全社 AI 環境

Claude Desktop（Cowork）の推論バックエンドを Amazon Bedrock にし、全社員向けの AI 環境を構築。最優先要件は「推論とデータを国内に閉じる」こと。国内リージョン間で完結、Microsoft Entra ID で ID 管理、監査証跡・コスト管理を完備。外部接続では MCP サーバーの OAuth 実装差を吸収する独自の認可中継サーバーを構築。

最大12万人規模設計〜全社リリース2週間推論・データ国内完結
Cowork on BedrockデータレジデンシーEntra ID監査

事例に見る"型"：「自社 AWS の統制下で Claude を使う」用途は、大きく ①全社 AI 基盤（Cowork on Bedrock）、②カスタマーサポート／コンタクトセンター（RAG 併用）、③自律エージェント（AgentCore）、④業務特化（営業・文書処理） に分かれます。共通する採用理由は、データレジデンシー・ガバナンス・レイテンシ／コスト／精度、そして既存 AWS への統合のしやすさです。
