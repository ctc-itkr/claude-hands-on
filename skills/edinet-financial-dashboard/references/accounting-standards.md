# 会計基準の説明：IFRS と JGAAP

このドキュメントでは、スキルが対応する2つの会計基準の違いについて説明します。

## 概要

| 項目 | IFRS | JGAAP |
|-----|------|-------|
| **正式名称** | 国際財務報告基準 | 日本基準 |
| **発行元** | IASB（国際会計基準審議会） | FSA・企業会計審議会（日本） |
| **対象** | グローバル企業 | 日本国内企業 |
| **特徴** | グローバル統一 | 日本国内中心 |
| **哲学** | 本質重視（Substance） | 保守的・安定志向 |

## 会計基準の主要な違い

### 1. 収益認識（Revenue Recognition）

**IFRS：**
- パフォーマンス義務が充足された時点で収益を認識
- より柔軟で、ビジネスの実態に即した認識
- 例：サービス提供の進捗に応じた部分的な収益認識

**JGAAP：**
- 明確な基準に基づいた一括認識
- 商品引渡しや完工基準など、具体的な時点で認識
- より保守的な認識基準

### 2. 有形固定資産の評価

**IFRS：**
- 取得原価モデル または 再評価モデル（任意選択）
- 固定資産の含み益を認識可能
- より柔軟な評価方法

**JGAAP：**
- 取得原価モデル のみ（強制）
- 含み益は認識しない（保守的）
- 減価償却方法も厳密に規定

### 3. 引当金（Provisions）

**IFRS：**
- 現在の債務がある場合に認識
- 蓋然性基準が低い（50%以上の可能性でOK）
- 引当金がより多くなりやすい

**JGAAP：**
- 過去の事象、現在の債務、支出の蓋然性が必要
- より保守的な認識基準
- 引当金がより少なくなりやすい

### 4. 現金流計算書（キャッシュフロー）

**IFRS：**
- 営業活動CF、投資活動CF、財務活動CFで区分
- 金利・配当は営業CFに含まれることが多い

**JGAAP：**
- 同じ区分だが、金利・配当の分類が異なる場合がある

## 指標の対応関係

### 売上高（Revenue）

| IFRS | 金額 | 日本基準 | 金額 |
|------|------|---------|------|
| `RevenueIFRS` | ✓ | `NetSales` | ✓ |

**違い：**
- IFRS：より広い範囲の収益を含む可能性（例：ライセンス料など）
- 日本基準：商品・サービスの売上が中心

### 営業利益（Operating Income）

| IFRS | 日本基準 |
|------|---------|
| `OperatingProfitIFRS` | `OperatingIncome` |

**違い：**
- IFRS：営業セグメント単位で計算
- 日本基準：販売費・一般管理費を明確に区分

### 純利益（Net Income）

| IFRS | 日本基準 |
|------|---------|
| `ProfitAttributableToOwnersOfParent`<br>（親会社帰属利益） | `Profit`<br>（当期純利益） |

**違い：**
- IFRS：少数派利益を控除した親会社帰属分のみ
- 日本基準：グループ全体の当期純利益が基本（子会社の少数派利益は別報告）

### 総資産（Total Assets）

| IFRS | 日本基準 |
|------|---------|
| `TotalAssetsIFRS` | `TotalAssets` |

**違い：**
- IFRS：時価評価の資産が含まれやすい
- 日本基準：取得原価が基本で、含み益は計上されない

## スキルでの判定と表示

このスキルは以下のロジックで会計基準を自動判定します：

```
1. XBRL内の要素をスキャン
2. "RevenueIFRS" や "IFRS" の出現回数をカウント
3. "NetSales" や "OperatingIncome" の出現回数をカウント
4. 多い方の基準を採用
5. ダッシュボードに該当基準の指標のみ表示
```

### ダッシュボード表示例

**IFRS企業：**
```
📊 会社名 財務ダッシュボード
🏢 会社名  📅 決算期: YYYY-MM-DD  [IFRS]
```

**日本基準企業：**
```
📊 会社名 財務ダッシュボード
🏢 会社名  📅 決算期: YYYY-MM-DD  [JGAAP]
```

## よくある質問

### Q: なぜ両方の基準に対応しているのか？

**A:** 日本の上場企業には以下のようなバリエーションがあります：
- 国内のみ上場：日本基準（JGAAP）
- 国際展開企業：IFRS
- 一部企業：両基準で報告

このスキルは全てのパターンに対応するため、両基準をサポートしています。

### Q: IFRS と日本基準、どちらが「正しい」のか？

**A:** 両方とも「正しい」です。異なるユースケースに対応しています：
- **IFRS**：国際的な比較可能性が必要な場合
- **日本基準**：日本の法令遵守・国内利害関係者への報告の場合

### Q: 数値が異なる場合がある？

**A:** はい。同じ企業でも会計基準によって数値が異なります。これは正常です：
- 収益認識のタイミング
- 資産評価方法
- 引当金の計算
