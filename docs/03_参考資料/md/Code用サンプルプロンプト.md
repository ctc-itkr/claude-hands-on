# Claude Code ハンズオン サンプルプロンプト集

スライドの流れに沿った、コピペ用のプロンプト集です。各プロンプトはスライド本文と一致しています。上から順に進めてください。

## 0. まず触ってみる（ウォームアップ）

```
金の重量(g)と純度(%)を入力すると買取概算額を計算できる、単一HTMLのツールを作ってください。
・外部ライブラリは使わず、1ファイル(index.html)で完結
・入力はフォーム、計算はその場で表示
・グラム単価は仮に 9,000円/g をコード内の定数に
作成後、ローカルで開いて動作を確認する手順も教えてください。
```

**狙い**：一言の指示でも、その場で動くツールができる感覚をつかむ。困ったらエラーをそのまま貼って、対話で直す。

## 1. 実際にやってみる（演習：XBRL → data.json → dashboard.html）

```
data/トヨタ自動車_E02144 の有価証券報告書XBRLから主要財務（連結・通期）を抽出して data.json にまとめ、その data.json から外部ライブラリなしの単一HTMLダッシュボード（dashboard.html）を作って。抽出・生成はスクリプトで行い、結果を見ながら仕上げて。
```

**狙い**：1社目（トヨタ自動車＝IFRS）で、XBRL → data.json → dashboard.html を通す。
**コスト作法**：巨大な XBRL 本文を会話に貼らない。構成 → 対象タグ → スクリプト化 → 結果だけ確認。

## 2. スキルにする（スキルは、プロンプトで作れる）

```
今やった「有価証券報告書XBRL → 主要財務の抽出 → ダッシュボード生成」の一連の手順を、
再利用できるスキルにまとめてください。
・入力（XBRLフォルダ）と出力（dashboard.html）を明記
・会社固有の値はハードコードせず、別の会社でもそのまま使えるように
作成後、このスキルの使い方（呼び出し方）も教えてください。
```

**狙い**：試行錯誤の成果を、そのまま“再利用できる資産”に変える。次からは「このスキルで、この会社を」と一言でよい。

## 3. 会計基準への対応（気づいた対応は、スキルに反映する）

まず別の会社（例：松田産業_E02821＝日本基準）に同じスキルを適用します。1社目（トヨタ自動車＝IFRS）と科目名やタグが変わる（売上収益 → 売上高 など）ので、差が出たら次のプロンプトでスキルに反映します。

```
日本基準の会社で必要になった科目の対応を、edinet-xbrl-dashboard スキルに反映して、
次からは自動で切り替わるようにしてください。
```

**狙い**：対応を一度スキルに書けば恒久化。次の会社からは、もう気にしなくてよい。

## 4. 自分でやってみる（課題）

- **好きな企業を追加**：配布データ以外の会社でも、同じスキルで作ってみる。
- **機能を足してみる**：バフェットコードを参考に、指標やグラフを追加。
- **企業どうしを比較**：2社を並べて、強み・弱みを見比べる。

## 困った時の助け舟

- まず Claude に聞いてみる。
- 完璧なプロンプトを目指さない（対話で育てる）。
- 確認が入ることがある（AIの時代でも、人間が判断する場面）。
