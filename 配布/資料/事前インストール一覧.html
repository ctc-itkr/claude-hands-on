Claude Code ハンズオン研修 — 事前インストール一覧

ゴール：参加者の Windows PC で Python が動き、Claude デスクトップアプリからスクリプトを実行できる状態。なお、Mac OSX では Claude デスクトップアプリ以外のインストールは不要です。

1. Claude デスクトップアプリ（Windows 版）〔インストール〕

研修で使う本体です。参加者はこのアプリ上で Claude にコードを書かせ、実行します。

  • 入手：公式サイト claude.com/download から Windows 版をインストール。

2. Python 3.x〔インストール〕

本研修では「Claude がその場で実際にプログラムを書いて動かす」体験が目標の1つです。その実行に Python を使います。PythonはClaudeが扱いやすい言語ですが、Windows には標準搭載されていません。

バージョンは、サポートが継続している Python 3 系であれば問いません。python（または python3）が動く状態になれば、入手方法も問いません。代表的な方法は次のとおりです。

  • python.org (python.org/downloads): 全ユーザー向け・一括配布がしやすく標準的。インストーラで「Add python.exe to PATH」を有効化してください。
  • Microsoft Store 版 : 管理者権限なしで入り、python3 コマンドも使えます。個別に入れる場合に手軽です。

完了確認：PowerShell で python --version（Store 版なら python3 --version）が通ればOK。

3. シェル〔次の (A)(B) どちらか一方〕

Claude が Python・コマンド を実行するには「シェル」が要ります。Windows ＋ Bedrock では既定でオフのため、どちらか一方をご用意ください（両方は不要）。

  • (A) Git for Windows をインストール : 付属の Git Bash を使い、追加設定なしで動作します。入手：git-scm.com/download/win から既定設定のままインストール。
  • (B) 環境変数を設定（インストール不要） : CLAUDE_CODE_USE_POWERSHELL_TOOL=1 を設定すると、Windows 標準の PowerShell をシェルとして使います。設定場所：Windows の環境変数（setx／GPO で一括配布可）、または Claude Code の settings.json の env。

目安：ソフト追加を避けたい／環境変数の一括配布がが可能な場合 (B)、アプリを一つ入れる方が運用しやすい場合 (A)。

追加ライブラリは不要

Python の標準ライブラリのみで完結します。pandas・lxml などのライブラリや、Node.js などの他ランタイムは使用しません。

完了の目安

Claude デスクトップアプリ →「Code」タブ → Local → 作業フォルダを選択 → 「Python で hello world を書いて実行して」でなどを実行できれば、準備完了です。
