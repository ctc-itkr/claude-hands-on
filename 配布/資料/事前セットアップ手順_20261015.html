手順 1：AWS Japan の記事に従ってセットアップする

セットアップ手順（AWS Japan）：zenn.dev：aws-bedrock-claude-cowork-setup
記事の手順を上から順に進めていただくと、Claude デスクトップアプリ・Bedrock への接続・Git Bash・Node.js・uv・仮想マシンプラットフォーム・MCP までが整います。

※ Node.js・uv・MCP（brave-search／chrome-devtools）は任意です。 Cowork の基本的な演習（プロンプトで資料やダッシュボードなどを作る課題）では使いません。ブラウザを操作してシステムを扱うオプション演習を行う場合にのみ、chrome-devtools（とその起動に使う Node.js）を設定してください。uv は MCP を設定するために AWS Japan の記事の手順でインストールしますが、今回設定する MCP（brave-search・chrome-devtools）はいずれも npx（Node.js）で起動するため、本ハンズオンでは uv を使う場面はありません。brave-search（Web 検索）は、外部 MCP・Web 検索を使えるかどうかが案件の方針によって変わりますので、方針を確認したうえで設定してください。

手順 2：Python のセットアップ（Code 用）

AWS Japan の記事には Python が含まれていません。Claude Code 用に、Python のインストールをお願いします。

Python 3.x

Claude Code の研修では、Claude がその場でプログラムを書いて実行します。その実行に Python を使うため、Windows にインストールしてください（Windows には標準では入っていません）。インストール方法はいくつかありますが、代表的には次のどちらかです。

  • 公式サイトからインストーラを入れる：Python の公式サイト python.org からインストーラをダウンロードして実行します。このとき、最初の画面にある「Add python.exe to PATH」のチェックを必ずオンにしてください（コマンドから Python を使えるようにするための設定です）。
  • Microsoft Store から入れる：Store で「Python」を検索してインストールします。管理者権限がなくても入れられます。

サポートが継続している Python 3 系であれば、どちらの方法でも構いません。インストールが終わったら、PowerShell で python --version を実行してください（うまくいかない場合は python3 --version も試してください）。バージョンが表示され、python または python3 のどちらかで Python を呼び出せる状態になっていれば完了です。

手順 3：動作を確認する

  • Code：Claude デスクトップアプリの「Code」タブで作業フォルダを開き、簡単な指示が実行できれば準備完了です。
  • Cowork：Claude デスクトップアプリの Cowork で作業フォルダを開き、簡単な指示が実行できれば準備完了です。
