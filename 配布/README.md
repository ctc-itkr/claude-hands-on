# Claude Code ハンズオン 配布一式

このフォルダは、ハンズオン当日に使う資料とデータの一式です。
Claude Code に「このフォルダ」を作業フォルダとして教えてから進めてください。
（事前準備は `資料/事前セットアップ手順_20261015.html` を参照）

## 説明スライド
- `研修スライド.pptx` … 研修の説明用スライド（このフォルダ直下・PowerPoint）。

## 演習で使う
- `資料/Code用サンプルプロンプト.html` … 演習で使うプロンプト集。この順に進めます。
- `データ/` … 演習用の有価証券報告書XBRL（全3社）。
  - プロンプトの `データ/<社名>_<EDINETコード>` が各社に対応します。
  - 例）`データ/AREホールディングス_E21187`
  - 収録: `AREホールディングス_E21187`、`キーエンス_E01967`、`三菱UFJフィナンシャルグループ_E03606`

## 参考資料（`資料/` フォルダ・読む用）
- `用語集.html` … 用語の早見表

## サンプル（完成イメージ＝ゴール例）
- `サンプル/` … ウォームアップで作る小ツール（`金買取概算計算ツール.html`）と、
  本演習で作る財務ダッシュボード（ARE・キーエンス）の完成例。手動で用意。

## 進め方
- `研修スライド.pptx` の説明を見ながら演習を進めます。
- プロンプトは自分で書いても、`資料/Code用サンプルプロンプト.html` をコピペしてもOKです。
- `サンプル/` の完成例を、作るもののゴールイメージにしてください。
