# Claude Code ハンズオン 配布一式

このフォルダは、ハンズオン当日に使う資料とデータの一式です。

## 説明スライド

- `研修スライド.pptx` : 研修の説明用スライド。

## 演習で使うデータ

- `データ/` : 演習用の有価証券報告書XBRL。プロンプトの `データ/<社名>_<EDINETコード>` が各社に対応します。
    - `AREホールディングス_E21187`
    - `キーエンス_E01967`
    - `三菱UFJフィナンシャルグループ_E03606`

## 参考資料

- `資料/` : 参考資料や演習で使うプロンプト集など
  - `事前セットアップ手順_20261015.html`: 事前セットアップ手順
  - `用語集.html` : 用語の早見表
  - `Code用サンプルプロンプト.html` : 演習で使うプロンプト集

## サンプル

- `サンプル/` : 完成イメージ 
  - ウォームアップで作る小ツール
  - 本演習で作る財務ダッシュボードの完成例

## 進め方
- `研修スライド.pptx` の説明を見ながら演習を進めます。
- プロンプトは自分で書いても、`資料/Code用サンプルプロンプト.html` をコピペしてもOKです。
- `サンプル/` の完成例を、作るもののゴールイメージにしてください。
