# Claude Code ハンズオン 配布一式

このフォルダは、ハンズオン当日に使う資料とデータの一式です。

```
配布/
├── README.md            … この案内
├── 研修スライド.pptx     … 研修の説明用スライド
├── 資料/                … 事前準備の手順・用語集・プロンプト集
├── データ/              … 演習で使う有価証券報告書のデータ
└── サンプル/            … 演習で作るものの完成例
```

## 進め方

1. 当日までに `資料/事前セットアップ手順_20261015.html` の手順で準備をします。
2. 当日は `研修スライド.pptx` の説明に沿って、演習を進めます。
3. プロンプト（Claude への指示文）は、自分で書いても、`資料/Code用サンプルプロンプト.html` からコピーして貼り付けてもかまいません。
4. 作るもののゴールは、`サンプル/` の完成例で確かめられます。

## 研修スライド

- `研修スライド.pptx` : 研修の説明用スライドです。

## 資料

- `資料/事前セットアップ手順_20261015.html` : 当日までに済ませておく準備の手順
- `資料/用語集.html` : 研修に出てくる言葉の早見表
- `資料/Code用サンプルプロンプト.html` : 演習で使うプロンプト集（スライドの流れの順に並んでいます）

## データ

`データ/` には、金融庁の EDINET（企業の開示書類を公開しているサイト）から取得した、有価証券報告書の XBRL（決算の数値をコンピューターで読める形にしたデータ）が入っています。会社ごとに `データ/<社名>_<EDINETコード>/` のフォルダに分かれています。

| フォルダ | 会計基準 | 演習での使い方 |
|---|---|---|
| `AREホールディングス_E21187` | IFRS（国際会計基準） | 1社目。ダッシュボードを作る |
| `キーエンス_E01967` | 日本基準 | 2社目。会計基準の違いに対応する |
| `三菱UFJフィナンシャルグループ_E03606` | 日本基準（銀行） | 課題用。銀行は「売上」などの意味が一般の会社と違うので、比べるときは注意 |

演習で作る `data.json`（抜き出した数値）と `dashboard.html`（ダッシュボード）は、それぞれの会社のフォルダの中にできます。

## サンプル

- `サンプル/金買取概算計算ツール.html` : ウォームアップで作る小さなツールの完成例
- `サンプル/AREホールディングス_財務ダッシュボード.html` : 1社目で作るダッシュボードの完成例
- `サンプル/キーエンス_財務ダッシュボード.html` : 2社目で作るダッシュボードの完成例

どれもブラウザで開くだけで見られます。
